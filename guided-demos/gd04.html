GD04 — Google AI Studio: Cleaning a Real Dataset

Session 4 · Wednesday, May 20, 2026  |  Chapter 3: Working with Data  |  Demo tool: Google AI Studio
Where this runs: Block A, after the Chapter 3 lecture and the Datawrapper walkthrough. Paced for roughly 20 minutes. This is a demonstration only — Google AI Studio requires users to be 18 or older, so students do not follow along. Their hands-on tool tonight is Datawrapper.

Before class — set up the demo

The demo lands only if students have just felt how tedious manual cleaning is. Have a genuinely messy table ready and let them see the mess first.

  • Sign in to aistudio.google.com with your Google account ahead of time, and open a fresh prompt.
  • Have the messy demo dataset below ready to paste — it is the Chapter 3 coffee-shop sales, deliberately dirtied with the four problem types from Section 3.2:
date,day_sales,category
2025-01-02,310,Regular
Jan 3 2025,295,regular
2025-01-04,,Regular
2025-01-04,,Regular
2025-01-05,4200,Holiday
2025/01/06,3.05,Regular
2025-01-07,288,REGULAR
  • Spot the planted problems so you can name them live: a missing value (Jan 4), a duplicate row (Jan 4 twice), an error (4200 — and 3.05, a price-style typo), and inconsistent formats (three date styles; "Regular" in four casings).
  • Mirror your screen; keep the Chapter 3 page open in a second tab for Section 3.2.

The Demo

1Frame the problem — show the mess⏱ 0:00 · ~3 min
👉 DO ON SCREEN Display the messy table above. Walk the four planted problems out loud, pointing at each cell: the blank, the repeated row, the impossible 4200, the three date formats.
🗣️ SAY "This is Section 3.2 in one little table — missing value, duplicate, error, inconsistent format. Cleaning this by hand is the 80% of data work nobody photographs. Let me show you a developer's tool that can take a first pass at it — and exactly where it still needs a human."
⚠️ WATCH OUT Keep this a demo, not a follow-along — AI Studio is 18+. Tell students plainly: watch this one; your tool tonight is Datawrapper, which has no age limit and no account.
2Open AI Studio and set a system instruction⏱ 0:03 · ~5 min
👉 DO ON SCREEN In AI Studio, find the System instructions field (separate from the chat box) and type a role for the AI: 
You are a careful data-cleaning assistant.
Standardize all dates to YYYY-MM-DD.
Make category capitalization consistent.
Remove exact duplicate rows.
NEVER guess or invent a missing value — leave it blank and flag it.
Flag any value that looks impossible instead of silently fixing it.
🗣️ SAY "This is what the Gemini chat box hides. A system instruction fixes the AI's job before it sees any data. Notice the most important line — never guess a missing value. That is Section 3.2 talking: a missing value is a question, not a blank to paper over. We are building our cleaning judgment into the tool's rules."
⚠️ WATCH OUT If the AI Studio layout has shifted, the System instructions field may be under a settings or panel toggle. The idea is what matters — a standing instruction, set apart from the prompt.
3Turn on structured output⏱ 0:08 · ~4 min
👉 DO ON SCREEN In the run settings, switch the response format from plain text to structured output (JSON). Point out that you are asking for clean, table-ready rows — not a paragraph describing the data.
🗣️ SAY "Structured output is the second thing the chat box hides. Normal chat gives you prose — nice to read, useless to load into Datawrapper or a model. Structured output forces clean, regular rows that drop straight into the next tool. This is the difference between AI as a chatbot and AI as a data-pipeline part."
⚠️ WATCH OUT Do not go deep on JSON syntax — this is an AI-literacy class, not a coding class. "Regular, table-shaped data" is the whole point; the brackets are just how the machine writes it.
4Run it on the messy data⏱ 0:12 · ~5 min
👉 DO ON SCREEN Paste the messy table into the prompt and run it. Put the result next to the original and read the changes against your four planted problems:
  • Dates — all three formats now YYYY-MM-DD.
  • Category — one consistent capitalization.
  • The duplicate Jan 4 row — removed.
  • The blank — still blank, and flagged, not invented.
  • The 4200 (and 3.05) — flagged as suspicious, not silently changed.
🗣️ SAY "Look at what it did and did not do. Formats and the duplicate — fixed; safe, mechanical work. The missing value and the impossible number — flagged and handed back to us. That is the tool respecting the rule we gave it. The machine did the tedious 80%; the judgment stays ours."
⚠️ WATCH OUT The model may behave imperfectly — it might still alter a flagged value, or miss one. Do not hide that. If it slips, name it: this is why a human reviews AI-cleaned data against the original. An imperfect run is a better lesson than a perfect one.
5Land the point — and hand off to the lab⏱ 0:17 · ~3 min
🗣️ SAY "Two takeaways. First — a system instruction plus structured output turns a chat model into a real data-cleaning aid, and you just watched one. Second, and bigger: the tool was only as good as the rules we wrote. We told it never to guess. A careless instruction — 'just make the data clean' — and it might have quietly filled that blank with an average and erased the question. Cleaning is judgment, whether a person or an AI does the typing."
👉 DO ON SCREEN — transition Close AI Studio. "Now it is your turn — with a tool every one of you can use." Pull up the Group Lab (GRP04) and send students to breakout rooms to build an honest chart in Datawrapper.
⚠️ WATCH OUT — if asked "can we use this?" Be direct: AI Studio is 18+, so it is not a graded task here. Students 13+ can get AI help on a dataset through Gemini (Chapter 1) — upload a file, ask questions — and then judge the answer with the cleaning eye this chapter gave them.

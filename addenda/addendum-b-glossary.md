Every key term from the eight chapters, in one alphabetical list. The chapter in parentheses is where the term is introduced; a few terms are revisited in a later chapter and show both.

**Accountability** — the principle that a person or organization is always responsible for an AI system's outcomes; "the algorithm decided" is never a complete answer. *(Chapter 8)*

**Accuracy** — the percentage of cases a model classifies correctly. *(Chapter 4)*

**AI project cycle** — the five stages of an AI project: define, gather, build, deploy, and evaluate. *(Chapter 1)*

**AI readiness** — an honest assessment of whether an organization has the clear problem, data, skills, and willingness an AI project needs to succeed. *(Chapter 8)*

**Algorithmic fairness** — the requirement that a system be measured for how well it performs across different groups of people, not just on average. *(Chapter 8)*

**Artificial intelligence (AI)** — building computer systems that perform tasks associated with human intelligence. *(Chapter 1)*

**Attention** — the transformer mechanism that weighs which words matter for which. *(Chapter 6)*

**Autonomous vehicle** — a vehicle capable of driving itself, classified by the levels of driving automation. *(Chapter 8)*

**Bounding box** — a rectangle a model draws around a detected object. *(Chapter 5)*

**Capstone project** — the course's culminating project: designing, building, testing, and analyzing a small AI-powered application that solves a real problem. *(Chapter 8)*

**Chatbot** — a program you interact with through conversation. *(Chapter 6)*

**Cherry-picked range** — showing only the slice of data that supports a chosen story. *(Chapter 3)*

**Citation** — a pointer to the exact source and place a claim came from. *(Chapter 2)*

**Classification** — predicting which predefined category a case belongs to. *(Chapter 4)*

**Classifier** — a model that performs classification. *(Chapter 4)*

**Cloud computing** — renting computing power and storage over the internet from a large provider, paying for what is used. *(Chapter 8)*

**Computer vision** — the field of teaching computers to work with images and video. *(Chapter 5)*

**Confidence score** — how strongly a model rates its own prediction. *(Chapter 5)*

**Content Credentials (C2PA)** — an industry standard attaching a tamper-evident origin label to media. *(Chapter 7)*

**Cross-checking** — confirming a claim against a second, independent, credible source. *(Chapter 2)*

**Curating** — deliberately gathering, evaluating, and organizing a trustworthy set of sources. *(Chapter 2)*

**Data** — recorded facts: numbers, text, images, measurements, and more. *(Chapter 2)*

**Data acquisition** — the process of collecting data. *(Chapter 2)*

**Data cleaning** — correcting errors and inconsistencies so data can be trusted. *(Chapter 3)*

**Data exploration** — examining a dataset's size, shape, and quality before using it. *(Chapter 3)*

**Data pipeline** — the system that moves data from where it is created to where a model uses it, cleaning and checking it along the way. *(Chapter 8)*

**Data transformation** — reshaping data, especially deriving new columns, to make it more useful. *(Chapter 3)*

**Data visualization** — turning numbers into a chart so a person can see the pattern. *(Chapter 3)*

**Datawrapper** — a free, browser-based tool for building clear, honest charts. *(Chapter 3)*

**Decision boundary** — the dividing line a classifier learns between categories. *(Chapter 4)*

**Decision tree** — a classifier that asks a sequence of yes/no questions. *(Chapter 4)*

**Deep learning** — machine learning using many-layered networks; the engine of the modern AI era. *(Chapter 1)*

**Deepfake** — synthetic but convincing AI-generated media depicting a real person doing or saying something they did not. *(Chapters 5, 7)*

**Derived column** — a new column calculated from existing ones, such as day-of-week from a date. *(Chapter 3)*

**Diffusion** — an image-generation method that refines random noise toward a prompt. *(Chapter 5)*

**Digital literacy** — the ability to find, evaluate, organize, and responsibly use information. *(Chapter 2)*

**Duplicate** — the same record entered more than once. *(Chapter 3)*

**Embedding** — the list of numbers representing a token, positioned by learned meaning. *(Chapter 6)*

**Faceprint** — the numeric summary of a face's measurements used for matching. *(Chapter 5)*

**Facial recognition** — identifying or verifying a person from an image of their face. *(Chapter 5)*

**Feature** — a single piece of input information used by a model. *(Chapter 1)*

**Filtering** — keeping only the rows relevant to a question. *(Chapter 3)*

**Gem** — a custom AI assistant built in Gemini from instructions you write. *(Chapter 6)*

**Generalization** — a model's ability to perform well on data it has not seen. *(Chapter 4)*

**Generative AI** — deep-learning systems that create new text, images, audio, or video. *(Chapter 1)*

**Generative chatbot** — a chatbot that generates fresh replies with a language model. *(Chapter 6)*

**Generative media** — image, audio, video, or text created by an AI model. *(Chapter 7)*

**Generative model** — an AI model that creates new content such as images. *(Chapter 5)*

**Grounding** — requiring an AI to answer only from a specific, chosen set of sources. *(Chapter 2)*

**Grouping and summarizing** — collapsing many rows into summary figures. *(Chapter 3)*

**Hallucination** — a confident, fluent, but false output from a generative AI system. *(Chapter 1)*

**Human-in-the-loop** — keeping a person able to review, question, and overrule an AI system, especially for high-stakes decisions. *(Chapter 8)*

**Human–robot interaction** — the design of robots that share space and work safely and predictably alongside people. *(Chapter 8)*

**Image classification** — predicting a single overall label for an image. *(Chapter 5)*

**Image segmentation** — labeling every pixel to trace the exact outline of objects. *(Chapter 5)*

**Imbalanced data** — data in which one category is far more common than another. *(Chapter 4)*

**Internet of Things (IoT)** — the network of everyday physical objects with sensors that connect to the internet and generate data. *(Chapter 2)*

**k-Nearest Neighbors (k-NN)** — a classifier that votes among the closest known examples. *(Chapter 4)*

**Label** — the correct answer attached to a training example. *(Chapter 1)*

**Large language model (LLM)** — a model trained on vast amounts of text to predict and produce language. *(Chapters 1, 6)*

**Levels of driving automation** — the standard 0–5 scale of how much a vehicle can drive itself; Level 2 still requires a responsible human driver, Level 4 is driverless within a defined zone, and Level 5 does not yet exist. *(Chapter 8)*

**Linear classifier** — a classifier that separates groups with a straight line or flat plane. *(Chapter 4)*

**Machine learning (ML)** — AI that learns patterns from examples instead of following hand-written rules. *(Chapter 1)*

**Machine translation** — converting text from one language to another. *(Chapter 6)*

**Missing value** — a blank entry where a value was expected. *(Chapter 3)*

**Model** — the learned pattern a system uses to make predictions. *(Chapter 1)*

**Model drift** — the gradual decline in a model's accuracy as the world changes and the present drifts away from the data it was trained on. *(Chapter 8)*

**Motion tracking** — following an object's movement across video frames. *(Chapter 5)*

**Multimodal AI** — an AI system that works with more than one kind of media at once. *(Chapter 7)*

**Music generation** — AI composition of original music from a prompt. *(Chapter 7)*

**Natural language processing (NLP)** — the field of teaching machines to work with human language. *(Chapter 6)*

**Neural network** — a classifier built from many simple units in layers, able to learn flexible boundaries. *(Chapter 4)*

**NotebookLM** — a Google research assistant that answers only from sources you provide and cites them. *(Chapter 2)*

**Object detection** — locating objects in an image, usually with bounding boxes. *(Chapter 5)*

**On-premises (on-prem)** — running computing on hardware an organization owns and operates in its own facilities. *(Chapter 8)*

**Overfitting** — when a model memorizes its training data instead of learning the general pattern. *(Chapter 4)*

**Pixel** — the smallest square unit of a digital image. *(Chapter 5)*

**Prompt** — the instruction a person gives an AI assistant. *(Chapter 1)*

**Provenance** — verifiable information about where a piece of media came from. *(Chapter 7)*

**Reinforcement learning** — learning by trial and error, guided by reward and penalty signals rather than labelled answers. *(Chapters 1, 8)*

**Robotics** — the branch of AI concerned with machines that perceive the physical world and act within it. *(Chapter 8)*

**Sense–think–act loop** — the continuous cycle by which a robot operates: gather sensor data, decide what to do, act physically, and sense again. *(Chapter 8)*

**Sentiment analysis** — judging the emotional tone of a piece of text. *(Chapter 6)*

**Source evaluation** — judging whether information can be trusted, using questions of authority, currency, evidence, purpose, and corroboration. *(Chapter 2)*

**Speech recognition** — converting spoken audio into text. *(Chapter 6)*

**Speech synthesis** — converting text into spoken audio. *(Chapter 6)*

**Structured data** — data organized into rows and columns, like a spreadsheet. *(Chapter 2)*

**Supervised learning** — learning from labelled examples, where the right answers are provided. *(Chapter 1)*

**Support vector machine (SVM)** — a classifier that draws the boundary with the widest margin between groups. *(Chapter 4)*

**Synthetic speech** — AI-generated spoken audio. *(Chapter 7)*

**SynthID** — Google's watermark that marks an image, audio clip, or video as AI-generated. *(Chapters 5, 7)*

**Temporal consistency** — keeping objects and motion coherent across video frames. *(Chapter 7)*

**Text-to-video** — generating a video clip from a text prompt. *(Chapter 7)*

**Token** — a standard small piece of text, a word or word-part, that a model processes. *(Chapter 6)*

**Tokenization** — cutting text into tokens. *(Chapter 6)*

**Training data** — the collection of examples a model learns from. *(Chapter 1)*

**Training set / test set** — the examples a model learns from / the held-out examples it is judged on. *(Chapter 4)*

**Transformer** — the 2017 neural-network design behind modern language models. *(Chapter 6)*

**Truncated axis** — a chart axis that does not start at zero, exaggerating differences. *(Chapter 3)*

**Unstructured data** — data with no fixed format, such as text, images, audio, and video. *(Chapter 2)*

**Unsupervised learning** — finding structure in unlabelled data, with no answers provided. *(Chapter 1)*

**Voice cloning** — recreating a specific person's voice from a sample. *(Chapter 7)*

**Watermarking** — embedding a detectable signal that marks media as AI-generated. *(Chapter 7)*

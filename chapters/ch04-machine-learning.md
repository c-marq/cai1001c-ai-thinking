**What this chapter will cover**

How machines learn patterns from examples instead of from hand-written rules. The major classification algorithms — k-nearest neighbors, decision trees, linear classifiers, support vector machines, and neural networks — in plain language. How to train a model and judge whether it is any good.

*Featured hands-on tool:* Teachable Machine and TensorFlow Playground.

Every chapter ends the same way: five review questions, a discussion question,
an instructor-led walkthrough, a breakout-group lab where you apply the tool to
your own idea, and an optional take-home that adds ethics and bias to the
reflection.
